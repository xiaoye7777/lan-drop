# 内网快传（lan-drop）

组内传文件、聊天的网页工具。只需要一台电脑运行服务，其他同事用浏览器打开网址就能用，什么都不用安装，也不需要连外网。

## 在内网电脑上部署（不需要联网）

仓库里已经包含编译好的代码（`dist/` 目录），运行时不依赖任何第三方包，**不需要 `npm install`，也不需要联网**。

1. 在能上网的电脑上打开 GitHub 仓库页面，点「Code → Download ZIP」下载压缩包。
2. 把压缩包拷到内网电脑上解压。
3. 启动：
   - **Windows：** 双击 `start.bat`。
   - **Mac / Linux：** 在解压出来的目录里运行：

     ```bash
     sh start.sh
     ```

### 内网电脑需要有 Node.js 20 或更高版本

内网电脑上要能运行 Node.js 20 或更高版本：

- **已经装了：** 直接用。
- **没装，但能安装：** 在能上网的电脑上去 nodejs.org 下载安装包，拷过去安装。
- **没有安装权限：** 下载免安装版，也就是 Windows 的 `node-v20.x.x-win-x64.zip`。解压后把文件夹改名为 `node`，放进项目目录，`start.bat` 会自动使用它。最终目录里应该有 `node\node.exe`。

### 启动之后

终端窗口会显示访问地址和访问口令，把这两项发给同事。关掉这个窗口，服务就停了。

- **访问地址：** 如果终端显示了多个地址，用公司内网的那个。
- **防火墙：** 系统询问是否允许 Node 接受连接时要选允许，否则同事打不开。
- **防止休眠：** 电脑休眠后全组都用不了。Mac 可以用 `caffeinate -i npm start` 启动，这样开着盖子不会休眠，但合上盖子仍会休眠。

### 第一次打开时浏览器提示“不安全”

为了加密传输，服务默认使用 HTTPS。证书由服务器自己签发，不是权威机构颁发的，所以浏览器第一次打开时会提示“您的连接不是私密连接”。点「高级」，再点「继续前往」即可。

- **连接仍然是加密的：** 局域网里的其他人看不到聊天内容和文件。
- **核对指纹：** 想确认连的确实是这台服务器，可以点地址栏左边的「不安全」，查看证书，核对 SHA-256 指纹是否和终端里显示的一致。
- **何时会重新提示：** 服务器电脑的 IP 变了、或者证书快到期（一年左右）时会自动换新证书，同事需要再点一次「继续前往」。
- **误用 `http://`：** 会自动跳转到 `https://`。

## 功能

### 基本功能
- 查看在线同事。对方离线也可以发，上线后能收到。
- 给个人或全组发文件：选择文件或直接拖进窗口，显示进度，可以取消和重试。图片会显示预览，点开能看大图。
- 发文字消息，新消息有未读数和标题闪烁提醒。
- 撤回：鼠标移到自己的消息上，点「撤回」。不限时间，撤回后服务器上永久删除，文件也一起删。只能撤回自己发的。已经下载过文件的人，手里的文件删不掉。

### 表情
- **内置 4 套，共 84 个：**
  - 「嘴替」大字报
  - 原创的「猪猪」和「猫猫」，由页面现场画出
  - 循环播放的「动图」
- **自定义表情：** 全组共享，支持 GIF 动图。只有添加的人能删除。

### 消息特效（仿 iMessage）
- **气泡特效：** 重击、大声、轻声、隐形墨水（点一下才显示内容）。
- **全屏特效：** 彩带、气球、烟花、爱心、炸弹。
- **使用方法：** 点输入框右边的 ✨ 选好特效，再发文字。系统设置了“减少动态效果”时不播放动画。

### 互动
点输入框左边的 ⊕ 可以发起以下几种互动：
- **投票：** 实名，可以设为多选。
- **接龙：** 每人一条，可以修改和撤回。
- **大转盘：** 结果由服务器抽取，发起人也没法提前知道。
- **五子棋：** 在全组发起时谁都可以应战，在私聊里发起时只有对方能应战。

### 个性化
点左下角自己的头像进入个人主页，可以设置以下内容：
- **头像：** 上传前会自动裁成正方形。
- **签名：** 一句话介绍自己。
- **名片背景：** 同事列表和资料卡里那一行的背景，分「普通」「稀有」「史诗」「传说」四档，传说级带动画。
- **聊天气泡：** 大家看到你发的消息都是这个样式。
- **聊天背景：** 只保存在自己的浏览器里，别人看不到，可以用自己的图片。

## 使用限制

- 单个文件最大 20 MB，不支持直接发文件夹。
- 文件 24 小时后自动删除，文字消息保留 7 天。
- 所有文件的总容量上限是 2 GB，满了之后要等旧文件过期。
- 同一个浏览器不要同时开太多标签页：同一网站最多 6 条连接，每个标签页占一条。

## 安全说明

- **传输：** 默认走 HTTPS 加密，私聊、群聊和文件在网络上都看不到明文。
- **服务器上的数据：** 消息和文件以明文保存在服务器电脑的 `data/` 目录里，能登录这台电脑的人能看到私聊内容。纯网页工具做不到让服务器本身也看不到内容（端到端加密），因为页面代码就是这台服务器提供的。
- **登录：** 进入需要组内口令，连续输错 10 次会被锁 10 分钟。私聊的消息、文件、投票只有双方能看到和操作。
- **上传的图片：** 头像、表情和图片预览只接受 PNG、JPEG、GIF、WebP，会根据文件内容判断格式，不看扩展名。尺寸大到可能拖垮浏览器的图片会被拒绝。即使有人把网页伪装成图片上传，也无法在浏览器里执行。
- **其他文件：** 一律按附件下载，不会在浏览器里直接打开。

## 配置

都是可选的环境变量：

| 变量 | 默认值 | 说明 |
|---|---|---|
| `LAN_DROP_PORT` | `8000` | 端口 |
| `LAN_DROP_HOST` | 所有网卡 | 只监听某个地址时才需要设置 |
| `LAN_DROP_HTTPS` | 开启 | 设为 `0` 关闭 HTTPS，内容会明文传输，不建议关闭 |
| `LAN_DROP_CODE` | 自动生成 | 访问口令 |
| `LAN_DROP_DATA_DIR` | `./data` | 数据目录 |
| `LAN_DROP_MAX_FILE_MB` | `20` | 单文件大小上限 |
| `LAN_DROP_MAX_STORAGE_GB` | `2` | 文件总容量上限 |
| `LAN_DROP_FILE_TTL_HOURS` | `24` | 文件保留时间 |

```bash
LAN_DROP_PORT=8001 npm start
```

Windows PowerShell 的写法是 `$env:LAN_DROP_PORT=8001; npm start`。

## 数据和口令

运行数据都在 `data/` 目录，不会进入 Git：

| 路径 | 内容 |
|---|---|
| `access-code.txt` | 自动生成的访问口令 |
| `tls/` | HTTPS 证书和私钥 |
| `users.json` | 同事、个人资料和登录会话（只存令牌的哈希值） |
| `messages.jsonl` | 消息记录，一行一条 |
| `files/` | 上传的文件，文件名是随机 id |
| `avatars/` | 头像 |
| `stickers.json`、`stickers/` | 自定义表情 |

- **换口令：** 删除 `access-code.txt` 后重启。已登录的同事不受影响。
- **让所有人重新登录：** 停止服务，删除 `users.json`，再启动。
- **换证书：** 停止服务，删除 `tls/` 目录，再启动。
- **清空全部数据：** 停止服务，删除整个 `data/` 目录。

### 发一个文件时发生了什么

1. 浏览器把文件的原始字节 `POST` 到 `/api/files?to=接收人&name=文件名`。
2. 服务器检查登录状态、大小和容量，把内容写入临时文件，再读文件开头判断它是不是可以预览的图片。
3. 写完后改成正式文件名，并追加一条文件消息。
4. 服务器通过 SSE 把消息推送给能看到它的人，对方页面立刻显示。
5. 对方下载或预览时，服务器再检查一次权限，然后返回文件。

### 投票、五子棋这类消息怎么更新

1. 消息发出后状态还会变，所有操作都发到 `/api/messages/<id>/actions`。
2. 服务器按 `activities.ts` 里的规则校验，比如是否轮到你、投票是否已结束，然后直接修改这条消息，并整个重写 `messages.jsonl`。
3. 改好的消息通过 SSE 推送给能看到它的人。页面收到后按 id 替换原来那条，再重画。

### 为什么这样设计

- **文件经服务器中转，不用 WebRTC 直连：** 只要能访问服务器的一个 TCP 端口就能用，对方离线也能收。
- **实时推送用 SSE，不用 WebSocket：** Node 内置模块就能实现，不需要第三方库。
- **HTTPS 和 HTTP 共用一个端口：** 服务器看连接的第一个字节，TLS 握手以 0x16 开头，其他的当作 HTTP，回一个跳转到 `https://` 的响应。
- **自己生成证书：** Node 没有生成证书的接口，`tls.ts` 按 X.509 标准手工拼出证书结构。这样 Windows 上没有 `openssl` 命令也能用。
- **不发 HSTS 响应头：** 证书是自签名的，发了 HSTS，浏览器就不再允许「继续前往」。
- **素材只存 id：** 名片背景、气泡、特效都只存 id，服务器只接受 `catalog.ts` 里有的 id。浏览器拿到的样式名都是已知的，不会把用户输入拼进页面。

## 开发

开发电脑需要联网安装 TypeScript：

```bash
npm install
npm run build
npm start
```

**改完代码，提交之前一定要运行 `npm run build`。** `dist/` 是给内网电脑直接运行的，不重新编译的话，内网下载到的还是旧代码。

```bash
npm test
```

`npm test` 会先构建，再运行 `src/test/` 里的测试：

| 文件 | 内容 |
|---|---|
| `server.test.ts` | 基础功能，启动真实的 HTTP 服务器 |
| `features.test.ts` | 新功能，包括真实的 HTTPS 握手 |
| `units.test.ts` | 证书、图片识别、五子棋判定 |

改完代码要重新执行 `npm run build`，然后重启服务。
